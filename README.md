# Data Science Portfolio

This repository contains the GitHub Pages portfolio website for **SONG Xuhuiyang**. The site presents a reproducible data-science project on synthetic student performance data, including the research question, key findings, visual evidence, methods, limitations, and project repository link.

## Local preview

The site is intended for GitHub Pages. With a Ruby/Jekyll environment:

```bash
bundle exec jekyll serve
```

## Deployment

GitHub Pages is configured to publish from the `main` branch and the repository root.
